## Before you install

**Windows** will warn about an unrecognised publisher, because the installer
is not code-signed. That warning means Windows has not seen this publisher
before, not that it found anything wrong. Choose **More info → Run anyway** if
you are happy to.

**Android** will ask permission to install from your browser, because this is
not from the Play Store. That prompt is Android doing its job.

**Local models** need [Ollama](https://ollama.com/download), which is a
separate free install. The app runs without it, but nothing will generate
until a model is available.

## Privacy

Your conversations, files and API keys stay on your machine. Cloud models are
only contacted if you add a key yourself, and web search only when you switch
it on. The app reports an install count with a random id and no content, and
that can be switched off in Settings.
